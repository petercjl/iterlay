# 画板库文件管理

画板库以目录树组织画板。左侧显示文件夹，顶部显示当前路径；目录信息保存在当前空间中，移动只改变归属，画板 ID、内容和素材引用保持稳定。

## 操作

- 新建文件夹，可继续建立子文件夹；通过菜单或 F2 重命名。
- 单击选择，双击或 Enter 打开画板和文件夹；勾选框或 Ctrl / Command 点击支持多选。
- 使用“移动到…”选择目标，或将选中的项目拖到文件夹、左侧目录或路径导航上。
- 画板与文件夹的右键菜单提供打开、重命名、复制、剪切、粘贴和删除；空白处右键可新建画板与文件夹。
- Ctrl / Command + C 复制、X 剪切、V 粘贴；复制文件夹包含子目录和画板，并生成独立画板身份。重名副本自动追加名称后缀。
- 新建与导入的画板归入当前文件夹，副本沿用原画板所在文件夹。
- 删除前显示确认。画板进入回收站；删除文件夹时递归将其中画板移入回收站，再移除目录。恢复画板时回到原目录，原目录已删除时回到根目录。

## 存储与协同

个人空间、公司本地空间与 NAS 空间各自保存目录。原有画板初始位于根目录，保持已有数据布局与打开方式。

本地目录元数据写入 `library/index.json`，使用现有原子写入与串行队列。NAS 目录写入组织隔离的文档表，与业务回执和审计在同一数据库事务中提交，提交后向在线客户端广播刷新。只读成员可以浏览，写入需要公司存储的写权限。

目录操作携带观察到的版本号。多人操作冲突时刷新目录并提示重试，避免覆盖他人的目录调整。目录移动不触发画板内容覆盖，也不改变画板协同版本。

## Agent 接口

`get_board_library` 获取目录、画板归属及目录版本；`manage_board_library` 使用 `expectedRevision` 和显式操作执行新建文件夹、重命名、移动、递归复制或删除空文件夹。桌面、CLI 与 NAS 使用同一份校验与权限契约。
