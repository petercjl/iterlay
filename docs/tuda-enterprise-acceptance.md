## 恢复与本机证据

- 新增企业源码前、恢复开发前及文档更新前保留了本机恢复点，位于忽略的 `tmp/`。
- NAS 已生成包含数据库、素材、运行配置、镜像身份的备份并校验 SHA256；在独立临时数据库成功还原 1 位成员、1 个画板，测试数据库已删除，当前服务数据保持独立。
- 双桌面截图与诊断位于 `output/playwright/tuda-enterprise-*`；集成测试代码位于 `enterprise/test/`。
- 部署具体地址、组织 ID、应用凭证、备份路径与用户标识保留在受保护的本机/部署记录，不写入公开源码及 npm 包。

## 发布前与后续范围

1. 当前是内网 HTTP/WS 开发部署；正式员工部署补齐 HTTPS/WSS 与对应回调。
2. 两名真实员工、Windows 与 Mac 交叉编辑、Windows 正式打包及更新验收尚未执行。
3. 当前离线编辑支持已打开画板；完全离线启动浏览、离职事件自动回收、定时备份与保留策略待补齐。
4. 企业视频/音频、模板和场景写入、评论标签、漫剧计费与图片交付等专门操作需要继续适配，当前会明确拒绝。
5. CLI 的既有 npm 结构审计提示发布生命周期与声明兼容项；测试和 CI 实际位于父仓库，不能把子目录扫描缺失等同于无测试。本次验证空间操作与构建，不声明 npm 发布准备完成。

本次没有发布 npm、Windows 正式版或网站。npm 包名仍为 `@petercjl/tuda`，版本保持 0.1.0，registry 尚无该包。
