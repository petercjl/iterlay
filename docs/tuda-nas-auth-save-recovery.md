# NAS 授权与保存恢复记录

日期：2026-11-13。

## 问题与修复

NAS 对每次画板、素材请求在线内省授权，共享账号服务原先对所有路由合计按 IP 限制 150 次/分钟。共享授权服务已由 codex-own 登录配置对话修复并部署：可信 NAS 内省独立按组织和 audience 限制 6000 次/分钟，其余请求保留原限制；每次请求继续查询数据库、校验权限与撤销状态。

NAS 现在区分内省限流、服务身份拒绝及上游不可用，保留安全的错误分类，不返回凭据或上游原始响应。

桌面同账号同 NAS 重连保留已观察的 CRDT 版本与编辑基线；更换账号或服务仍清理隔离状态。画板保存采用服务端返回的实际 revision，只改变视口时可以维持原版本号，避免客户端虚增版本引发冲突和额外读取。

## 验证

- 授权错误分类、存储重连、账号、NAS 路由、保存协调器与连续视口保存回归测试通过。
- Electron 类型检查、企业服务编译、前端编译通过。
- NAS 更新后的服务健康。Docker Hub 元数据请求超时，因此用现有运行镜像构建仅替换错误分类段落的派生镜像；源码同步保留，数据库与素材目录保持原样。
- 共享授权服务 7 项测试通过；从 NAS 连续发起 160 次内省均返回 HTTP 200，无效令牌全部 active:false，缺失服务凭据返回 401。云端证据由 codex-rebuild 的授权服务交接记录维护。
- Mac Dev 实际打开公司画板，视口缩放恢复到原值 50%，随后返回画板库，最终界面未显示未保存提示。
