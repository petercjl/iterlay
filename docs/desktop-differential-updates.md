# Tuda 桌面更新发布

从 0.1.11 起，稳定桌面版本通过原有「检查更新」入口提供最新版完整安装包。稳定包清单使用 npm `@petercjl/tuda-desktop@latest`，预发布完整安装清单使用 `next`。每次正式发布须提供 macOS arm64 和 Windows x64 制品。支持的旧版按平台和架构直接安装目标版本，画板、设置和登录状态继续从用户数据目录读取。

1. 分别在 macOS 和 Windows 构建对应的完整安装包，记录精确版本、源码和 SHA-256。
2. 使用旧整包版和曾采用差分的版本验证原按钮、直接升级、重新打开和原数据恢复。
3. 上传并验证完整安装器的内容分块，再通过 npm-release-kit 发布完整清单，回读公开版本、标签、平台和安装器哈希。

## 差分发布历史

0.1.9 是当时的过渡版。0.1.10 曾为 0.1.9 按精确起始版本和平台发布差分。0.1.11 的完整清单版本高于该历史差分，已安装历史版本的客户端因此能直接选择 0.1.11 完整安装包。后续正式发布沿用完整清单。
