# 账号密码登录与访客媒体

Tuda 保留企业钉钉登录，同时支持管理员分配的账号密码。访客账号只使用独立本地空间，文本和图片请求经公司授权服务处理，上游模型 Key 保留在服务端。

## 身份与存储

`POST /api/company/v1/auth/password` 接收 appId=tuda、username、password，返回独立的 company-v1 设备会话。服务端使用独立访客身份域和 scrypt 密码哈希；账号登录按 IP 与规范化账号进行数据库限流。停用、重置密码和到期后拒绝新调用；停用与重置撤销现有会话。

`/bootstrap` 为访客返回 text.transport=proxy、image.adapter=company-proxy 与 storage.enabled=false。`/direct-models`、`/storage/token` 和跨应用调用对访客拒绝；客户端不接收上游 Key。钉钉员工继续使用既有的文本直连、个人 ToAPIs 配置和独立 NAS 权限合同。

访客画板、素材、历史与模板保存在当前应用数据目录下 `guest-workspaces/<账号命名空间>/`；Agent 配置按账号与空间隔离。切换账号使旧异步存储上下文失效。访客界面显示本地空间，主进程拒绝切换企业空间。

## 图片任务

`POST /image/jobs` 接收 requestId、model、prompt、resolution、aspect 与参考图，返回任务 ID。`GET /image/jobs/:id` 查询状态；成功后通过 `GET /image/jobs/:id/assets/:index` 获取图片。三类接口都要求当前 Tuda 会话并检查任务所有者。

服务端复用固定版本 `@petercjl/toapiscli@0.1.1` 执行 ToAPIs MCP 操作，Key 从服务端私有挂载读取。可用模型由 CLI 免费查询后返回；模型限制、尺寸与参考图在提交前检查。任务的账号、请求 ID、参数摘要和状态记录在 PostgreSQL，CLI 请求和产物保存在独立持久化卷。相同请求 ID 和参数返回原任务；参数冲突拒绝；结果不明时查询原请求，不自动新建付费任务。每账号同时允许一个正在提交或运行的图片任务。

## 管理与交付

授权服务的 `guest-admin.ts` 从标准输入接收管理操作，支持创建、列举、停用、启用和重置密码。创建可指定 expiresAt；无公开注册接口。管理员可让当前 Agent 执行“创建 Tuda 账号”“停用 Tuda 账号”或“重置 Tuda 账号密码”，说明准确账号和必要约束。

登录密码文件只交付给管理员并采用用户私有权限；ToAPIs Key 不包含在用户登录信息中。云端数据库、配置与原镜像保留恢复点。Mac 开发验证、Windows 正式版和 npm 发布分别记录。
